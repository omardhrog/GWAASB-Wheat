# GWAASB-Wheat

A reproducible **grain-yield(`GY`)** workflow for integrating genomic prediction and stability analysis in multi-environment wheat trials.

## Scope

The pipeline implements:

- environment-specific BLUE estimation;
- genomic relationship matrix construction;
- GBLUP and GBLUP-G×E models;
- leakage-controlled CV1 and CV2;
- within-environment prediction accuracy;
- genomic G×E-effect matrix extraction;
- GWAASB calculation by singular-value decomposition;
- comparison with phenotypic WAASB, GE row standard deviation, and Wricke's ecovalence;
- joint assessment of predicted genomic performance and stability.

## Privacy boundary

This repository is intentionally restricted to **grain yield (`GY`)**.

## Experimental design and first-stage analysis

The original field experiment used a **balanced split-plot design** with
three replications in each year × location. Sowing date was assigned to
whole plots and genotype to subplots. The whole-plot error is associated
with replication × sowing date; the subplot residual represents the
second error stratum.

The pipeline now defaults to an **executable full-data split-plot BLUE
estimator** (`STAGE1_FULL_METHOD <- "splitplot"`). It fits
`lme4::lmer(GY ~ REP + DATE * GEN + (1 | REP:DATE))` separately
within each year × location, then uses `emmeans` to estimate GEN
means for each DATE/ENV. This requires ENV labels of the form
`year1.D1.loc01`; it assumes each REP × DATE is a randomized whole
plot. The original within-environment method is still available using
`STAGE1_FULL_METHOD <- "within_env"`.

**Reproducibility qualification:** CV1 and CV2 continue to use the
original **training-only**, within-environment `lm(GY ~ REP + GEN)`
adjustment. This prevents full-data leakage but does not refit a
split-plot mixed model within each fold. Therefore the full-data BLUE
estimator and CV first-stage estimator differ, and the current code
should not be described as a fully split-plot-based CV pipeline.

The manuscript also reports across-environment REML variance components
and 1,000 parametric bootstrap replicates. These are **not generated by
this genomic pipeline**. The reported results must be traceable to the
separate variance-component analysis; they must not be attributed to
the `stage1_splitplot` function.

The manuscript reports BGLR settings of 12,000 iterations, 4,000 burn-in,
and thinning of 5 for the full-data models. The current script uses
those settings for the full-data models, but uses 5,000 iterations and
1,500 burn-in for CV to reduce computation. The CV settings must be
reconciled with the reported analysis before asserting exact numerical
reproducibility. No prediction accuracies or variance components have
been recomputed by this documentation change.

## Required input files

Place these files in the R working directory (normally the repository root), or edit `POP_FILES`:

| File | Required structure |
| --- | --- |
| `phenotype_data_DHLS-1.csv` | `ENV, GEN, REP, GY`; ENV must encode year, date, location for split-plot mode |
| `phenotype_data_DHLS-2.csv` | `ENV, GEN, REP, GY`; same ENV format |
| `SNP_clean_fixed_DHLS-1.csv` | `GEN` followed by SNP-marker columns |
| `SNP_clean_fixed_DHLS-2.csv` | `GEN` followed by SNP-marker columns |

SNP genotypes may be coded as `0/1/2` or `-1/0/1`. Missing marker values are mean-imputed when the genomic relationship matrix is constructed.

## Run

```r
source("R/GWAASB_Wheat_GY_pipeline.R")
```

The default analysis uses two populations, excludes parents `G101` and `G102`, retains 100 DH lines per population, and performs 100 repetitions of five-fold CV1 and CV2. These settings can be changed in the **SETTINGS** section.

## Outputs

All generated files are written to `results/`, including marker-QC summaries, environment BLUEs, genomic predictions, GWAASB values, stability comparisons, CV summaries, environment-specific metrics, validation predictions, and session information.
